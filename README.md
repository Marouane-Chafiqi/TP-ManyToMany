# hiber1

Projet Java qui utilise **Hibernate 4** et **MySQL** pour gérer des salles, des machines, des utilisateurs (étudiants et employés) et des cours, avec des relations OneToMany, ManyToMany et de l'héritage. Ouvrable dans NetBeans et IntelliJ (via `pom.xml`).
